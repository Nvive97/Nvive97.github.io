Política de privacidad

Finanzas · Última actualización: 26 de octubre de 2026

Quién la usa

Finanzas es una herramienta de uso personal. La usa únicamente su autor para organizar sus propias finanzas. No se ofrece al público.

Qué datos de Google usa y para qué

  • Google Drive / Google Sheets (permiso drive.file): solo puede ver y editar los archivos que la propia app crea o que el usuario abre con ella. Se usa para guardar y leer la hoja de cálculo de finanzas del usuario. No tiene acceso al resto de su Drive.
  • Gmail (solo lectura, cuando se habilite): se usará únicamente para leer las notificaciones de compra y estados de cuenta que el banco envía al usuario, con el fin de registrar sus gastos. La app no envía, borra ni modifica correos.

Dónde se guardan los datos

Los datos se guardan en la hoja de Google Sheets privada del usuario, dentro de su propia cuenta de Google. Las credenciales de acceso se guardan como secretos fuera del código fuente. La app se ejecuta con la asistencia de Claude (Anthropic), que procesa los datos solo para realizar estas tareas.

Con quién se comparten

Con nadie. Los datos no se venden, no se usan para publicidad y no se transfieren a terceros, salvo lo necesario para que la app funcione según lo descrito arriba.

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
